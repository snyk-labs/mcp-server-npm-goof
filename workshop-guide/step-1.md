# Step 1

## Goals

- Get familiar with the MCP Server codebase and its structure
- Understand how to start and run the MCP Server
- Explore the tools, resources and prompts exported by the MCP Server

## Your Tasks

In this step, we will setup the MCP Server project, your job is to complete the following tasks:

1. Clone this project to a local directory
2. Install the dependencies using `npm ci`
3. Start the server using `npm start`
4. Check that the server is running and that you can find MCP server tools, resources and prompts exported by the server
